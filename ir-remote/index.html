  • IR link: Generated the 38 kHz NEC carrier from a hardware timer rather than a software delay loop, so the carrier period stays inside the receiver's decode window.
  • Emergency stop: Put the stop on an interrupt so it runs ahead of the main control loop instead of waiting on it.
  • Feedback: Drove a buzzer and a vibration motor from MCU GPIO through active-low PNP stages, so the operator gets a response without looking at the remote.
  • Menus: Wrote the LCD menu as a state machine so each screen has one place that handles its inputs.
